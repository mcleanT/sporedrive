# Figure Quality Standards

Reference for figure composition and analysis agents. All figures generated by the pipeline MUST comply with these standards.

---

## Color Palette

**Categorical (colorblind-safe):**
```
["#0072B2", "#D55E00", "#009E73", "#CC79A7", "#F0E442", "#56B4E9", "#E69F00"]
```

**Sequential:** viridis or plasma colormaps only.

**NEVER use:** red-green combinations, jet/rainbow colormaps.

**Auto-apply:** `from autonomous_science.analytics import *` applies the colorblind-safe theme automatically.

---

## Typography

| Element | Size | Style |
|---------|------|-------|
| Axis labels | 12pt | Bold |
| Tick labels | 10pt | Regular |
| Titles | 14pt | Bold |
| Legend | 10pt | Regular |

Font family: Arial or Helvetica.

---

## Resolution & Format

- Minimum **300 DPI** for all raster output.
- Publication figures: **PDF or SVG** (vector).
- Pipeline intermediate figures: PNG is acceptable.
- Always set `constrained_layout=True` on the figure.
- No clipped labels — check margins before saving.

---

## Data Visualization Rules

- **Error bars** on all means — label whether SEM or 95% CI.
- **Jitter or swarm plots** for N < 30. Do not use bar charts for small N.
- **Sample sizes** in axis labels or annotations: e.g., `"Group A (n=15)"`.
- **No 3D plots** unless the data is inherently three-dimensional.
- Adequate margins; verify no labels are clipped after `constrained_layout`.

---

## Multi-Panel Composites

- Consistent axis scaling across comparable panels.
- Panel labels: uppercase letters (A, B, C, ...) in top-left corner, **16pt bold**.
- Shared legends where panels share the same color encoding.
- Include a figure caption placeholder as a markdown comment below the save call.

---

## Code Template

```python
import matplotlib
matplotlib.use('Agg')  # Non-interactive backend — required for subprocess execution
import matplotlib.pyplot as plt
from autonomous_science.analytics import *  # auto-applies colorblind-safe theme

fig, axes = plt.subplots(1, 2, figsize=(12, 5), constrained_layout=True)

# Panel A
ax = axes[0]
# ... plotting code ...
ax.set_xlabel("X Label", fontsize=12, fontweight='bold')
ax.set_ylabel("Y Label", fontsize=12, fontweight='bold')
ax.set_title("Panel Title", fontsize=14, fontweight='bold')
ax.text(-0.1, 1.05, 'A', transform=ax.transAxes, fontsize=16, fontweight='bold')

# Panel B
ax = axes[1]
# ... plotting code ...
ax.text(-0.1, 1.05, 'B', transform=ax.transAxes, fontsize=16, fontweight='bold')

fig.savefig('output.pdf', dpi=300, bbox_inches='tight')
plt.close(fig)
# Caption: [Figure caption goes here]
```

---

## Gate Checks

Before finalizing any figure script:

1. **No `imread`/`imshow` for compositing** — composite figures must assemble panels programmatically, not by loading rasterized images of other figures.
2. **All figures generated from source data** — no screenshots or pre-rendered images embedded via `imshow`.
3. **`matplotlib.use('Agg')` at the top** of every script that runs in a subprocess.
4. **`plt.close(fig)`** after every `savefig` to prevent memory leaks across multi-panel runs.
